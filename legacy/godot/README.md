# Прототип на Godot (архив)

Исходная версия 0.2 «Орков с района» на Godot 4: движок правил `scripts/game.gd`, стол `scripts/table.gd`, тесты `tests/`, инструменты снимков `tools/`, старые скриншоты `output/`.

Текущая игра — Rust и Bevy в `crates/`. Этот каталог оставлен для сверки правил и не участвует в сборке. Пути `res://` здесь указывают на прежнюю структуру проекта, поэтому без переноса файлов он не запустится.
